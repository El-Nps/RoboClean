
# Arduino

[← Hardware](../README.md) | [Battery →](../Battery/README.md)

The project uses an Arduino Nano board from Franzis.

For information about the [firmware](../../firmware/README.md), see the corresponding page.

### Pins: 

Motorcontroller 1: 
IN1: D10	BACK_RIGHT
IN2: D9  	FORWARD_RIGHT
IN3: D6  	BACK_LEFT
IN4: D5  	FORWARD_LEFT

Motorcontroller 2:
IN1: D12	VACUUM_HIGH
IN2: D8  	VACUUM_LOW
IN3: D11	BRUSH_HIGH
IN4: D7  	BRUSH_LOW

Motor Encoder Left: D3
Motor Encoder Right: D2

Sensor left: A0
Sensor middle: A1
Sensor Right: A2
