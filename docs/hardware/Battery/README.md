
# Battery

[← Arduino](../Arduino/README.md) | [Raspberry Pi →](../RaspberryPi/README.md)

The project uses a 3200 mAh Li-Ion battery made for the Ecovacs Deebot Ozmo 900.

| Specification | Value |
| --- | --- |
| Configuration | 4S |
| Nominal voltage | 14.8 V |
| Capacity | 3200 mAh |
| Nominal energy | 47.4 Wh |
| Dimensions (L × W × H) | 133.6 mm × 37.2 mm × 20.4 mm |

For further information, please contact the [manufacturer](https://www.reichelt.de/de/de/shop/produkt/ersatzakku_ecovacs_deebot_ozmo_li-ion_3200_mah-324502).

The battery can be charged with a lab power supply. The charger we've ordered is unable to charge the battery (for unknown reasons).
